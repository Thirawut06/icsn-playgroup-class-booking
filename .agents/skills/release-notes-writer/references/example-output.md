```markdown
# บันทึกการอัปเดต v1.1.0

📅 13 กรกฎาคม 2569

---

✅ เพิ่มใหม่

**ฝั่งผู้ปกครอง**
- ผู้ปกครองสามารถแก้ไขข้อมูลส่วนตัวและรูปภาพของเด็กได้เองจากหน้าจองคลาส
- เพิ่มการแจ้งเตือนเมื่อยังไม่ได้อัปโหลดรูปภาพของเด็ก ระบบจะไม่ให้จองจนกว่าจะครบ

**ฝั่งแอดมิน**
- แอดมินสามารถเพิ่ม/ลดเครดิตให้ผู้ปกครองได้โดยตรง พร้อมบันทึกเหตุผล
- เพิ่มหน้าจัดการ Trial Package — สามารถให้เครดิตทดลองกับผู้ปกครองใหม่ได้ในคลิกเดียว

---

🔧 ปรับปรุง

- ปุ่ม "จองคลาส" แสดงจำนวนที่นั่งคงเหลือชัดเจนขึ้น ถ้าเต็มจะขึ้นว่า "เต็มแล้ว" และกดไม่ได้
- ข้อมูลการจองใน Google Sheets อัปเดตเร็วขึ้นหลังมีการเปลี่ยนแปลง

---

🐛 แก้บั๊ก

- แก้ปัญหาวันที่แสดงผิดสำหรับผู้ใช้ในประเทศไทย (เลื่อน 1 วัน)
- แก้ปัญหาแอดมินไม่สามารถดูรายการจองที่ถูกยกเลิกในแดชบอร์ด

---

⚠️ ต้องระวัง

- ผู้ปกครองที่ยังไม่มีรูปภาพของเด็กในระบบ จะไม่สามารถจองคลาสได้จนกว่าจะอัปโหลดรูปให้ครบ
```

## สิ่งที่ทำให้ output นี้ดี

| เกณฑ์ | ตัวอย่าง |
|---|---|
| ไม่มีศัพท์ tech | ✅ "อัปโหลดรูปภาพ" แทน "upload to Storage bucket" |
| เน้นสิ่งที่ผู้ใช้ทำได้ | ✅ "สามารถแก้ไขข้อมูลได้เอง" แทน "EditProfileModal added" |
| สั้น ได้ใจความ | ✅ 1 ประโยคต่อ bullet |
| แยก audience | ✅ ฝั่งผู้ปกครอง / ฝั่งแอดมิน ชัดเจน |
| ⚠️ ต้องระวัง ชัดเจน | ✅ บอกผลกระทบที่ผู้ใช้จะเจอจริง |
| ตัดหมวดว่าง | ✅ ไม่มีหัวข้อว่างๆ ที่ไม่มีเนื้อหา |
