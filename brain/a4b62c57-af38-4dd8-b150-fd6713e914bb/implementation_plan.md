# แผนการปรับปรุง UX/UI สำหรับระบบจัดการวันหยุด (Admin Calendar Refinement)

ปัญหาที่แอดมินพบคือความสับสนในการใช้งาน (Cognitive Load สูง) ทั้งเรื่องการเลือกวัน (Single/Range/Multi), การตั้งค่าที่ทับซ้อนกัน (Force Open ทับกับ Closed), และการยกเลิกค่า (Reset) ที่หาได้ยาก

## 🎯 1. การจัดการความซ้ำซ้อนของข้อมูล (Data Overlap Resolution)
**ปัญหา:** 
1. กด "บังคับเปิด" ซ้ำซ้อน ทำให้มี Record ในฐานข้อมูลขยะเยอะ
2. หากเคยกด "บังคับเปิด" ไปแล้ว แต่อยากเปลี่ยนใจเป็น "ปิดรับจอง" แอดมินมักจะกดปิดรับจองไปเลยโดยไม่ได้กด Reset ก่อน ทำให้มี Record 2 อันตีกัน (และเปิดจะชนะปิดเสมอตามโค้ดล่าสุด)

**วิธีแก้ปัญหา (Convergence):**
- **ปรับ Logic ฝั่ง Database (RPC `set_date_status`):** เมื่อมีการสั่ง "ปิดรับจอง" หรือ "บังคับเปิด" ในช่วงวันใดๆ ระบบจะทำการ **ลบ (Delete) การตั้งค่าพิเศษทั้งหมดที่มีอยู่เดิมในวันนั้นๆ ทิ้งก่อนโดยอัตโนมัติ** (เสมือนการทำ Auto-Reset) แล้วค่อย Insert ค่าใหม่เข้าไป
- **ผลลัพธ์:** แอดมินไม่ต้องเรียนรู้ปุ่ม Reset อีกต่อไป! แค่อยากให้เป็นอะไรก็กดปุ่มนั้นได้เลย ระบบจะเคลียร์ของเก่าให้เอง ไม่มีวันทับซ้อน 100% ส่วนปุ่ม Reset จะทำหน้าที่แค่ "ลบเพื่อกลับไปใช้ค่า Default ของระบบ" เท่านั้น

## 🎯 2. การควบรวมโหมดการเลือกวัน (Unified Selection UX)
**ปัญหา:** แอดมินงงว่าทำไมต้องมี Single, Range, Multi โหมดเยอะแยะ และทำไมแก้รายรอบ (Session) ได้แค่ในโหมด Single

**เหตุผลเดิม (Why it was built this way):**
การแก้รายรอบเรียน (เช่น ปิดแค่รอบเช้า) ระบบจำเป็นต้องรู้แน่ชัดว่า "วันนั้น" มีรอบเรียนอะไรบ้าง ถ้าเลือกหลายวัน (Multi/Range) บางวันอาจจะมีรอบเช้า บางวันไม่มี การแก้รายรอบทีละหลายๆ วันพร้อมกันจึงทำได้ยากและอาจเกิดบั๊ก

**วิธีแก้ปัญหา (Convergence):**
- **ยุบรวมโหมด Single และ Multi เข้าด้วยกัน:** 
  - ให้หน้าจอเริ่มต้นมีแค่โหมด **"เลือกอิสระ" (Click to Select)**
  - แอดมินสามารถคลิกวันที่บนปฏิทินกี่วันก็ได้
  - **ความฉลาดของ UI:** ถ้าแอดมินเลือก **1 วันถ้วน** ระบบจะแสดงเมนู "แก้ไขรายรอบ (Session)" ขึ้นมาให้เห็นอัตโนมัติ แต่ถ้าเลือก **2 วันขึ้นไป** เมนูแก้ไขรายรอบจะซ่อนไป และเหลือแค่เมนู "ปิด/เปิด ทั้งวัน"
- **ย้ายโหมด Range (เลือกเป็นช่วง) ไปซ่อนไว้:** แอดมินส่วนใหญ่ไม่ได้หยุดยาวบ่อยๆ การมีช่องใส่วันเริ่มต้น-สิ้นสุด ตลอดเวลาทำให้ดูรก เราจะทำปุ่มเล็กๆ ว่า *"เลือกเป็นช่วงยาว (Long Holiday)"* เพื่อเปิดโหมดนี้เมื่อจำเป็นเท่านั้น

## 🎯 3. การแสดงผลและการยกเลิกที่มองเห็นง่าย (Visibility & Color Coding)
**ปัญหา:** รายการที่ตั้งพิเศษ (Upcoming Settings) อยู่ด้านล่างแอดมินมองไม่เห็น และการยกเลิก (Undo) ทำได้ยาก

**วิธีแก้ปัญหา (Convergence):**
- **Calendar-First Undo:** แอดมินไม่ต้องเลื่อนไปลบที่รายการด้านล่าง แค่เห็นสีบนปฏิทินผิดปกติ -> คลิกที่วันนั้น -> กดปุ่ม "ยกเลิกค่า (Reset)" จากแผงควบคุมหลักได้เลย (ใช้ความคุ้นเคยเดิม)
- **ปรับสีให้สื่อความหมายชัดเจน (Color Coding):**
  - ⬜ **วันเปิดปกติ:** สีขาว/ปกติ
  - ⬛ **วันหยุดประจำสัปดาห์ (Default):** สีเทา
  - 🟩 **บังคับเปิดพิเศษ (Force Open):** สีเขียวสดใส + มีไอคอน (เช่น 🌟) ให้รู้ว่าแอดมินเป็นคนเสกมันขึ้นมา ไม่ใช่ระบบ
  - 🟥 **ปิดรับจองพิเศษ (Holiday/Closed):** สีแดง + มีไอคอน (เช่น ⛔)
