# การอัปเดตไฟล์ SQL ให้ตรงกับ Database ล่าสุด (Sync Schema)

เนื่องจากโปรเจ็กต์นี้ใช้ Supabase หากคุณมีการแก้โครงสร้าง Table หรือเพิ่ม Function ใหม่ผ่านหน้าเว็บ Supabase Dashboard คุณสามารถดึงโค้ด SQL ล่าสุดกลับมาเก็บไว้ในโปรเจ็กต์ได้ง่ายๆ ครับ

## วิธีการดึงข้อมูล SQL โดยไม่ต้องใช้ Docker (Docker-Free)
เนื่องจากคำสั่งมาตรฐานของ Supabase CLI จำเป็นต้องเปิดใช้งาน Docker Desktop ในการจำลองฐานข้อมูลเพื่อเปรียบเทียบความต่าง ซึ่งอาจทำให้รันคำสั่งได้ยากและขึ้น Error

ทางเราได้สร้างสคริปต์ Node.js สำหรับเชื่อมต่อเพื่อดึงโครงสร้าง SQL ให้คุณแบบตรงๆ (ไม่จำเป็นต้องเปิด Docker) ไว้ให้เรียบร้อยครับ โดยให้ปฏิบัติตามขั้นตอนดังนี้:

### ขั้นตอนการรันสคริปต์เพื่อดึง Schema:
1. ไปที่เว็บไซต์ Supabase Dashboard โปรเจ็กต์ของคุณ
2. ไปที่เมนู **Settings** (รูปเฟือง) -> **Database**
3. เลื่อนลงมาที่หัวข้อ **Connection string** แล้วเลือกแท็บ **URI**
4. ติ๊กถูกที่ช่อง **Use connection pooling** (โหมด Transaction)
5. ก๊อปปี้ URL ที่ได้มา (อย่าลืมแก้ช่อง \[YOUR-PASSWORD]\ ให้เป็นรหัสผ่าน Database จริงๆ ด้วย)
6. เปิด Terminal ขึ้นมาในโฟลเดอร์โปรเจ็กต์ แล้วรันคำสั่งต่อไปนี้:
\\\ash
node database/dump-db-metadata.js
\\\
7. ระบบจะให้คุณ **วาง Connection String (URI)** ที่ก๊อปปี้และแก้รหัสผ่านเรียบร้อยแล้วลงไป กด Enter

สคริปต์จะเชื่อมต่อไปยังฐานข้อมูล Supabase และสร้าง/เขียนทับไฟล์ SQL เหล่านี้ให้โดยอัตโนมัติทันทีครับ:
- \database/tables.sql\ (โครงสร้างตารางอัปเดตล่าสุด)
- \database/functions.sql\ (ฟังก์ชัน RPC ทั้งหมดอัปเดตล่าสุด)
- \database/policies.sql\ (นโยบายความปลอดภัย RLS ทั้งหมดอัปเดตล่าสุด)
