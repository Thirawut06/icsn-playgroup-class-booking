# Domain Glossary

- **Session**: A time slot on a specific date for a playgroup class. It has a capacity and can hold bookings.
- **Session Template**: A recurring configuration for sessions (e.g., "Morning Slot", 10 capacity). Used to generate sessions.
- **Booking**: A reservation for a child to attend a specific session.
- **Parent**: The user account that manages children and creates bookings.
- **Child**: The attendee of the playgroup class, managed by a Parent.
