# บันทึกการอัปเดต v1.0.0

📅 13 กรกฎาคม 2569 · เปิดตัวระบบครั้งแรก

---

✅ เพิ่มใหม่

**ฝั่งผู้ปกครอง**
- สมัครสมาชิกและล็อกอินด้วยอีเมล พร้อมระบบกู้คืนรหัสผ่านทางอีเมล
- กรอกใบสมัครเด็กพร้อมอัปโหลดรูปภาพและเซ็นชื่อดิจิทัลได้ในแอป
- จองคลาสจากปฏิทิน เห็นที่นั่งคงเหลือแบบ Real-time ก่อนกด
- ยกเลิกการจองได้ด้วยตนเองก่อนเวลาที่ทางโรงเรียนกำหนด
- ดูยอดเครดิตคงเหลือ ซื้อแพ็กเกจ และส่งสลิปโอนเงินผ่านแอปได้เลย
- แจ้งเตือนอัตโนมัติเมื่อโรงเรียนปิดหรือหยุดพิเศษ
- รองรับทั้งภาษาไทยและภาษาอังกฤษ สลับได้ตลอดเวลา

**ฝั่งแอดมิน**
- ดูข้อมูลผู้ปกครองและเด็กทั้งหมด พร้อมแก้ไข Notes ได้
- อนุมัติสลิปชำระเงิน ระบบเติมเครดิตให้ผู้ปกครองอัตโนมัติ
- ตั้งจำนวนที่นั่งและเปิด/ปิดคลาสรายวันได้เอง
- บันทึก Walk-in สำหรับเด็กที่มาหน้าโรงเรียนโดยไม่ได้จองล่วงหน้า
- เช็คอินเด็กรายวันจากหน้าแอดมิน
- จัดการวันหยุดและวันปิดโรงเรียนพิเศษ
- ปรับเครดิตให้ผู้ปกครองได้โดยตรง พร้อมบันทึกเหตุผล
- กำหนดเวลา cutoff, จำนวนที่นั่ง Default และชั่วโมงทำการได้เอง
- แดชบอร์ดสรุปสถิติการจอง, เครดิต และการชำระเงินรายวัน
- แจก Trial Credits ให้ผู้ปกครองใหม่ได้ในคลิกเดียว

**ระบบอัตโนมัติ (ทำงานเบื้องหลัง)**
- ไฟล์สลิป รูปภาพเด็ก และลายเซ็นถูกบันทึกลง Google Drive อัตโนมัติ
- ข้อมูลการจองซิงค์ไป Google Sheets ทันทีที่มีการเปลี่ยนแปลง
- แจ้งเตือนทีมงานทาง Google Chat เมื่อมีการจอง ยกเลิก หรืออนุมัติสลิป

---

⚠️ ต้องระวัง

- ผู้ปกครองที่ยังไม่ได้อัปโหลดรูปภาพของเด็ก จะไม่สามารถจองคลาสได้จนกว่าจะอัปโหลดให้ครบ
- การยกเลิกการจองต้องทำก่อนเวลา cutoff ที่ทางโรงเรียนกำหนด มิฉะนั้นระบบจะไม่อนุญาต
