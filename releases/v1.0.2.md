# บันทึกการอัปเดต v1.0.2

📅 15 กรกฎาคม 2569

---

🔧 ปรับปรุง

**ฝั่งผู้ปกครอง**
- ปรับโฉมหน้าจองคลาส (Booking) สำหรับหน้าจอคอมพิวเตอร์ (PC) ให้ใช้งานแบบ Native เต็มจอ แทบไม่ต้องเลื่อนจอ และให้ปฏิทินเลื่อนเกาะติดสายตาลงมาตลอดเวลา
- ปรับดีไซน์แถบเมนูด้านบน (Header) บนหน้าจอคอมพิวเตอร์ ให้รวบเป็นแถวเดียว (Single App Bar) เพื่อคืนพื้นที่แนวตั้งให้กับหน้าจองคลาส

**ฝั่งแอดมิน**
- แก้ไขเลย์เอาต์สำหรับ iPad แนวตั้ง ให้เมนูแถบด้านบนสามารถเลื่อนซ้าย-ขวาได้ (Scrollable Tab)
- แก้ไขปัญหาตัวอักษรและข้อมูลซ้อนทับกันในเมนูต่างๆ ของระบบหลังบ้าน เพื่อให้อ่านและจัดการข้อมูลได้ง่ายขึ้น

**🛠 ระบบภายใน (Internal & Performance)**
- ลบโฟลเดอร์ Sentry Example และลบแพ็กเกจ `googleapis` กับ `recharts` ที่ไม่ได้ใช้งานแล้วออกจากโปรเจกต์ เพื่อลดขนาดไฟล์รวมของระบบและลดความเสี่ยงจากช่องโหว่ความปลอดภัยของส่วนเสริมเก่าๆ
- ตั้งค่าระบบตรวจสอบคุณภาพโค้ดอัตโนมัติ (CI/CD) ผ่าน GitHub Actions แบบทำงานขนานกัน (Parallel) เพื่อบังคับให้มีการเช็คโค้ดและทดลอง Build ทุกครั้งก่อนนำขึ้น Production ช่วยลดข้อผิดพลาดจากการรวมโค้ดและทำให้การตรวจสอบเสร็จเร็วขึ้น
- เพิ่มบอท Dependabot เพื่อคอยตรวจสอบเวอร์ชันของแพ็กเกจเสริมต่างๆ ทุกสัปดาห์ หากพบช่องโหว่ความปลอดภัยหรือมีเวอร์ชันใหม่ บอทจะทำการเปิด Pull Request เพื่อแจ้งเตือนให้ทีมพัฒนาเข้ามาตรวจสอบและตัดสินใจอัปเดต (บอทจะไม่ทำการอัปเดตระบบเองโดยพลการ)
